# Growth-model review checklist

Mark each item PASS or FAIL and record the evidence or correction. PASS means the brief meets the stated criterion, not that the business hypothesis has been validated. These review gates are package adaptations of the cited principles.

For a hypothesis brief, unknown rates can pass if visibly labeled and paired with a concrete evidence plan. Paid-only fields may be marked PASS, not applicable, when the mechanism does not use acquisition capital. Do not excuse a missing closing transition by marking it unknown: a proposed loop must at least specify a testable reinvestment mechanism.

## Decision and context

- [ ] PASS / FAIL: The brief recommends a concrete next decision and states its horizon.
- [ ] PASS / FAIL: Core audience, problem, and meaningful value behavior are explicit. [S4]
- [ ] PASS / FAIL: Observations, inferences, assumptions, and unknowns are distinguishable; an unproven first model remains a hypothesis. [S4]
- [ ] PASS / FAIL: Acquisition, retention, and monetization motions fit the product context and their dependencies are visible. [S2] [S4]

## Loop integrity

- [ ] PASS / FAIL: Each selected loop names input, participant action, output, reinvestment, and next eligible input. [S2]
- [ ] PASS / FAIL: The closing transition explains how usable output powers the next cycle rather than relying on a circular diagram. [S2]
- [ ] PASS / FAIL: Participants have a value-based reason to perform the behavior. [S1] [S4]
- [ ] PASS / FAIL: Acquisition and engagement outputs are separated; repeated exposures, existing users, and same-account joins are handled explicitly.
- [ ] PASS / FAIL: The strongest candidates receive priority; the strategy is not a catalogue of unsupported loops. [S2]

## Activation and retained value

- [ ] PASS / FAIL: Activation includes setup, initial value, and a first habit cycle; incomplete activation is reported separately. [S5]
- [ ] PASS / FAIL: The activity event reflects value, and any claim that it predicts retention has evidence or is labeled a hypothesis. [S5]
- [ ] PASS / FAIL: Habit frequency fits natural usage; a one-period active count is not presented as habitual retention. [S5]
- [ ] PASS / FAIL: B2B success uses the appropriate account or team unit, and engaged free populations are included where relevant. [S5]
- [ ] PASS / FAIL: Retention cohorts have a clear activation boundary and enough follow-up; selection does not conceal activation losses.

## Quantification and economics

- [ ] PASS / FAIL: Transition rates specify events, units, denominators, periods, and evidence status. [S2]
- [ ] PASS / FAIL: Calculations use compatible conditional rates, avoid duplicate counts, and yield eligible next-cycle inputs.
- [ ] PASS / FAIL: Reproduction ratio, retained contributions, and external inputs are distinguished; no ratio is treated as a guarantee of compounding.
- [ ] PASS / FAIL: Cycle time and a common comparison horizon are present; influential uncertainty is shown.
- [ ] PASS / FAIL: A paid loop traces collected contribution cash, reinvestment, and payback; booked revenue or LTV is not substituted for available fuel. [S3]
- [ ] PASS / FAIL: Attribution evidence is described with limitations rather than asserted as precise causal credit. [S6]

## Investment, execution, and decline

- [ ] PASS / FAIL: The selected intervention addresses an evidenced or explicitly hypothesized constraint and names its racecar role. [S3]
- [ ] PASS / FAIL: Pricing, prompts, and other changes protect activation and retained value while supplying fuel. [S3]
- [ ] PASS / FAIL: One accountable owner has cooperating functions, committed capacity, and stated dependencies. [S2] [S4] [S6]
- [ ] PASS / FAIL: Learning has a hypothesis, relevant evidence, observation window, success condition, stop condition, and next decision.
- [ ] PASS / FAIL: The method suits the uncertainty; strategic questions are not buried under tiny conversion tests. [S1]
- [ ] PASS / FAIL: Saturation, rising costs, or weakening output trigger review, with product or mechanism reinvention considered. [S1] [S6]
- [ ] PASS / FAIL: Expert guidance is attributed accurately; illustrative calculations and thresholds are identified as adaptations.

## Common failure modes and fixes

| Failure | Why it fails | Fix |
| --- | --- | --- |
| Funnel with a decorative return arrow | No reinvestable output is identified. [S2] | Name the closing transition and the next cycle's eligible input. |
| Publicity calendar described as an engine | Temporary spikes are mistaken for repeated growth. [S3] | Specify which engine receives the seed and how it repeats. |
| More invitations presented as more customers | Exposure, existing users, and eligible acquisition are conflated. | Deduplicate and follow recipients through the relevant value boundary. |
| Login reminders used to fix failed setup | The chosen activity misses value and activation. [S5] | Diagnose initial value and habit before retention messaging. |
| Paid-only or user-only retention | Free distribution contributors or account health disappear. [S5] | Add free cohorts and the correct B2B value unit. |
| Lowest conversion rate automatically prioritized | Percentage size ignores denominator, feasibility, and repeated effects. | Compare feasible absolute changes over one horizon. |
| LTV:CAC used as cash availability | Lifetime economics do not establish recycling speed. [S3] | Model collections, contribution costs, reinvestment, and payback. |
| Monetization or referral pressure damages usage | More fuel weakens the engine. [S3] | Evaluate net output and protect meaningful activity and retention. |
| Every department optimizes its own stage | Upstream wins can damage downstream outcomes. [S2] | Assign a shared loop outcome and cross-functional owner. |
| A new hire is asked to invent the first model | Context is replaced by an imported playbook. [S4] | Keep founder accountability and validate organic behavior first. |
| Endless tactical tests on an exhausted mechanism | Optimization misses a strategy or saturation problem. [S1] | Revisit the engine hypothesis and examine adjacent value. |
| Fixed ratios projected indefinitely | Costs, audience availability, and product value change. [S6] | Bound forecasts and define deterioration triggers. |

## Release rule

Correct all material failures before delivery. If the missing piece is business evidence, deliver a clearly labeled hypothesis with a bounded validation plan and explain which conclusion remains unavailable. Never present fabricated measurements as a fix.
