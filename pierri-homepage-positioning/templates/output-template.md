# Homepage copy skeleton

Fill with the user's facts. The finished output is the copy itself; keep the champion choice, market-state reading and value ranking in your head. Drop any section the input cannot support. The core sequence (hero, problem, solution, value, proof, action) follows Pierri's public summary; the exact layout is a package convention.

*Written for: [primary champion, one line, optional].*

**Hero**
- Headline: [familiar category + real difference, or exact job + how it changes the current way; under ~10 words]
- Subheadline: [who it is for and how it works, one or two sentences]
- CTA: [action that fits the sales motion]

**Problem** [the champion's current way and where it breaks, two to three sentences, only if it helps the argument]

**How it works** [the product in two to four steps or one short paragraph]

**Value sections (two to four)**
- Heading: [what the user can now do]
- Copy: [what makes it possible and which limitation it removes, one to three sentences]

**Proof** [only proof from the input: customers, numbers, quotes; otherwise omit the section]

**Closing CTA** [one line + button text]
