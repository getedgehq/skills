# Review checklist

Mark each applicable item Pass or Fail. Mark an item Not applicable only with a reason. A proposal is ready when all applicable checks pass. Missing evidence can pass only when clearly labeled and accompanied by a proportionate verification plan; claims of known performance cannot.

## Attribution and evidence

- [ ] Pass / Fail: Credits Simon Kaiser and distinguishes his statements from agency practice and this package's adaptations.
- [ ] Pass / Fail: Describes the five-part long-form rationale as synthesis; never claims to reproduce MEEDIA's locked five reasons.
- [ ] Pass / Fail: Every factual method or case claim has a matching [S#] in sources.md, with support at the stated level of specificity.
- [ ] Pass / Fail: Podcast attribution stays within the fetched show notes; no invented audio quotations or timestamps.
- [ ] Pass / Fail: Case figures are historical, self-reported where appropriate, and qualified by period and metric.
- [ ] Pass / Fail: No inaccessible commissioned study is presented as independently reviewed; no results are promised from the case.
- [ ] Pass / Fail: Source language is paraphrased, with at most one short quoted phrase per source; no paywalled text or third-party skill content is reproduced.

## Audience and channel

- [ ] Pass / Fail: Defines an audience interest and situation beyond a broad demographic such as Gen Z.
- [ ] Pass / Fail: Distinguishes observations, audience hypotheses, and proposed creative choices.
- [ ] Pass / Fail: Gives a specific channel promise and credible brand contribution.
- [ ] Pass / Fail: Explains why people would voluntarily watch and return.
- [ ] Pass / Fail: Hosts, collaborators, and account structure fit the audience promise and production capacity.
- [ ] Pass / Fail: Community participation has an owner, realistic capacity, and a path into future content decisions.

## Format and episode

- [ ] Pass / Fail: A repeatable episode engine can produce a meaningful slate, not merely one campaign film.
- [ ] Pass / Fail: Runtime earns depth, entertainment, or connection; it is not set by a universal length claim.
- [ ] Pass / Fail: Brand relevance appears in the action or useful explanation without delaying the promised experience.
- [ ] Pass / Fail: Title, thumbnail, and opening promise the same thing and truthfully match the episode.
- [ ] Pass / Fail: A new viewer can understand the episode with minimal background.
- [ ] Pass / Fail: The current episode delivers its payoff and offers a relevant reason to view another.
- [ ] Pass / Fail: Format complexity, release rhythm, factual review, and commercial disclosure are feasible for the brief.

## Distribution and learning

- [ ] Pass / Fail: Long-form, Shorts, collaborations, and paid each have a justified job where included.
- [ ] Pass / Fail: Paid expansion requires defined evidence of useful viewing rather than simply weak organic reach.
- [ ] Pass / Fail: Organic and paid results are separated, and cross-format viewer conversion is measured only when evidence exists.
- [ ] Pass / Fail: Time with Brand has an explicit metric, content scope, and time window and is identified as a proxy.
- [ ] Pass / Fail: Watched minutes, retention, return behavior, relevant audience signals, and business outcomes are not conflated.
- [ ] Pass / Fail: Cost per watched minute uses consistent cost scope and matching valid viewing data.
- [ ] Pass / Fail: The pilot has an owner, feasible batch, review date, justified targets, and continue/change/stop conditions.
- [ ] Pass / Fail: Recommendations preserve the user's goal and do not imply unauthorized publishing, spending, or outreach.

## Common failure modes and fixes

| Failure | Why it fails | Fix |
| --- | --- | --- |
| Inventing Kaiser's exact five reasons | The requested MEEDIA list is inaccessible. | Use the labeled synthesis and state the access boundary. |
| Stretching content to 30 minutes | Runtime replaces viewer value. | Cut padding; make length a hypothesis tied to the experience. |
| Uploading corporate films and buying reach | Distribution substitutes for audience fit. | Rewrite around a recurring audience promise and test attention quality. |
| Selecting creators by follower count | Reach does not establish brand or format compatibility. | Examine audience interests, tone, and the creator's actual contribution. |
| Copying the WG sitcom for every category | Surface imitation loses the transferable mechanism. | Match format to audience tension, credible brand role, and resources. |
| Making every episode depend on old lore | New viewers cannot enter the series. | Establish immediate stakes and supply only necessary context. |
| Using a cliffhanger instead of the promised result | The episode fails its own audience promise. | Resolve the current arc, then introduce a fresh next question. |
| Removing all product relevance | Enjoyment no longer supports a distinct brand association. | Make the brand's contribution specific and natural. |
| Banning Shorts on principle | Public practice assigns Shorts useful complementary roles. | Give Shorts an audience-matched job and test deeper viewing. |
| Counting views or subscribers as the entire outcome | Reach hides attention quality and return behavior. | Add watched minutes, retention, audience relevance, and business evidence. |
| Calling watch time sales lift | A viewing proxy is treated as causal commercial proof. | Qualify the proxy and request suitable action or brand research. |
| Importing case growth targets | Historical, integrated results are treated as a forecast. | Use relevant baselines and explicit pilot hypotheses. |
| Treating historical media percentages as a budget recipe | Denominators and overlap are unclear. | Build a current scoped media plan with validated options. |
| Requiring proprietary agency tools | Tool choice replaces the public decision method. | Use available analytics and document data limits. |
| Producing faster than the team can learn | Capacity pressure prevents iteration. | Reduce complexity or cadence and keep the review cycle. |

## Final evidence check

Read the brief from the viewpoint of someone who has never seen these references. They should be able to distinguish the recommendation, the viewer benefit, the brand contribution, the production commitment, the measurement plan, and the unknowns. If those remain unclear, revise the deliverable before suggesting implementation.
