# Review Checklist

For each applicable item, mark **PASS** or **FAIL** and note the evidence or repair. Mark **N/A** only with a scope reason, such as an audit that does not include production. A missing material fact can pass only if it is explicitly disclosed and the recommendation remains appropriately provisional. Do not mark an unsubstantiated claim as passed because a source link exists elsewhere.

These checks apply Denney's method; traceability and causal-interpretation checks are package safeguards rather than quotations from the expert.

## Evidence and diagnosis

- [ ] **PASS / FAIL:** The assignment identifies the offer, business objective, available inputs, and production constraints.
- [ ] **PASS / FAIL:** Research includes relevant customer problems and objections alongside praise; AI-derived patterns have been checked against underlying material. [S3] [S4]
- [ ] **PASS / FAIL:** Observations, interpretations, and hypotheses are distinguished with retrievable evidence locators. Package safeguard.
- [ ] **PASS / FAIL:** Each priority persona names a concrete buying trigger; demographic context changes a meaningful creative choice. [S6]
- [ ] **PASS / FAIL:** Buyer evidence and current ads' implied audiences are mapped separately, or their absence is disclosed. [S3]
- [ ] **PASS / FAIL:** Frequency and emotional intensity have separate rationales; sample findings are not presented as market prevalence. [S3] Package safeguard.
- [ ] **PASS / FAIL:** The diagnosis links a specific evidence gap to the proposed tests and would not justify arbitrary creative. [S3] [S8]
- [ ] **PASS / FAIL:** Competitor-derived personas remain provisional and competitor ad longevity is not treated as proof of profitability. [S3]

## Concepts and production

- [ ] **PASS / FAIL:** Each concept has one main persuasive angle that remains recognizable across formats. [S2] [S7]
- [ ] **PASS / FAIL:** Relevant messaging lenses clarify the idea without forcing a concept quota. [S2]
- [ ] **PASS / FAIL:** The intended awareness entry matches what the buyer is assumed to know; expansion is considered when existing ads only address purchase readiness. [S2] [S5] [S8]
- [ ] **PASS / FAIL:** Creator, imagery, setting, and format are selected for credibility and communication, with an explanation of their fit. [S2]
- [ ] **PASS / FAIL:** Product claims, demonstrations, and testimony are supportable; no review distortion, invented endorsement, or fabricated lived experience appears. Package safeguard.
- [ ] **PASS / FAIL:** Selected briefs include a persona, short idea, and three messaging options, with hook variants distinguished from separate angles. [S3]
- [ ] **PASS / FAIL:** Proof assets, objections, production dependencies, and a learning question are explicit. Package safeguard.
- [ ] **PASS / FAIL:** The roadmap covers meaningfully different needs or messages and explains priority, capacity, and cadence. [S3] [S6]
- [ ] **PASS / FAIL:** Relevant supporting content mismatches are identified within the assignment's scope. [S8]

## Measurement and learning

- [ ] **PASS / FAIL:** Commercial outcomes are separated from viewing, click, and interaction diagnostics. [S2]
- [ ] **PASS / FAIL:** Comparison context and changed variables are recorded; conclusions do not isolate format, creator, or angle without adequate evidence. Package safeguard.
- [ ] **PASS / FAIL:** Insufficient exposure and other material limits can lead to an inconclusive status; universal success thresholds have not been invented. Package safeguard.
- [ ] **PASS / FAIL:** Content, internal comparison, relevant external context, and customer feedback inform the interpretation. [S2]
- [ ] **PASS / FAIL:** Every selected test has a proposed next decision, and new findings can revise the diagnosis or backlog. [S3] [S7]

## Common failure modes and fixes

| Failure | Fix |
| --- | --- |
| Audience is only an age or gender label | Find the event or problem that changes buying motivation; retain demographic context only when useful. [S6] |
| Roadmap is a list of grids, carousels, and talking heads | Rebuild around buyer needs and angles, then map formats to those concepts. [S2] [S6] |
| Persona sounds convincing but has no source evidence | Inspect original research; mark provisional or remove unsupported details. [S3] |
| AI brief is polished but generic | Conduct a manual evidence pass and edit the brief around a concrete diagnosis. [S3] |
| Three hooks are counted as three strategic concepts | Keep one concept ID and label opening variants unless the persuasive premise changes. [S2] [S3] |
| Competitor longevity substitutes for evidence | Use the ad as inspiration, find a customer signal, and write a hypothesis for this account. [S3] [S7] |
| Click-through or watch time determines the winner | Reassess against the business objective; use engagement to investigate why results differ. [S2] |
| Format gets credit when talent and message also changed | Report a concept-level result and plan a follow-up that can clarify the explanation. Package safeguard. |
| Product promise outruns available proof | Narrow to a supportable claim, obtain proof, or defer production. Package safeguard. |
| Weekly reactions replace a roadmap | Reconnect weekly tasks to monthly tests and a broader coverage plan suited to the assignment. [S6] |
| Winning script is pasted into another format unchanged | Preserve the angle while adapting the headline, visual proof, and pacing to the execution. [S5] [S7] |
| No response plan for a losing or inconclusive test | Specify the evidence needed for revision, further research, or stopping before launch. Package safeguard. |

## Review disposition

Write: **[Ready / Ready with disclosed limitations / Revise]**.

List any failed applicable items, their repairs, and remaining unknowns. A deliverable is ready only when material unsupported claims and misleading performance conclusions have been removed. An evidence-limited exploratory plan can be ready when its provisional status and learning boundaries are clear.
