# Positioning review checklist

Internal review: run it silently on your draft and fix what fails. Never put this checklist, PASS/FAIL marks, a review note or a list of limitations in the deliverable; a gap that matters to the user becomes one short open question at the end (three at most). The gates are package adaptations of the public method, not a scoring system published by the expert.

A definitive handoff requires every gate to pass. A provisional canvas can be handed off with failed evidence or testing gates only when the unresolved decisions and validation plan are explicit. Do not represent provisional work as established positioning. Fabricated evidence and unsupported current capabilities must be removed before any handoff.

## Pass/fail gates

- [ ] **Present offering:** Claims concern available capabilities; future vision is separately labeled. Pass if today's buyer rationale stands without roadmap promises. [S8]
- [ ] **Evidence integrity:** Material observations have evidence identifiers and limitations. Hypotheses are visible. Pass if internal ideas are not presented as customer findings. [S7]
- [ ] **Real alternatives:** The buyer's current approach and actual shortlisted options are included. Pass if merely theoretical rivals do not drive the position. [S2] [S3]
- [ ] **Bounded differentiation:** Every primary difference names its comparison and mechanism. Pass if vague superiority has been replaced by something demonstrable. [S2]
- [ ] **Value trace:** Each primary value theme connects a difference to an enabled action and meaningful buyer consequence. Pass if the alternative cannot adequately deliver the same claimed advantage in this situation. [S1] [S2] [S4]
- [ ] **Strong customer fit:** Observable conditions explain who cares intensely. Pass if a seller can recognize likely fit and the analysis names where it weakens. [S4]
- [ ] **Viable focus:** The chosen niche has a plausible commercial rationale. Pass if narrowness has not replaced consideration of reach and business goals. [S6]
- [ ] **Frame comparison:** At least two plausible contexts are compared. Pass if the selected frame centers differentiated value and important implied expectations are credible for the target. [S4] [S5]
- [ ] **Category risk:** The framing style and its education burden are explicit. Pass if new category creation is justified rather than assumed necessary for growth. [S2] [S6]
- [ ] **Honest gap diagnosis:** Apparent lack of differentiation has been checked against wins, internal understanding, and segment fit. Pass if any remaining offer gap is reported instead of concealed. [S1]
- [ ] **Messaging follows analysis:** The buyer explanation traces to the completed canvas. Pass if appealing prose is not used as evidence that the strategy works. [S4] [S7]
- [ ] **Validation:** Suitable buyer feedback is recorded, including contradictory observations. Pass if comprehension and choice assumptions have actually been checked; a plan alone leaves this gate failed and the canvas provisional. [S4]
- [ ] **Operational handoff:** Relevant pricing, channel, product, sales, and support implications are recorded. Pass if the category decision is more than a wording change. [S4] [S6]
- [ ] **Reviewability:** The canvas is dated, uncertainty is clear, and change triggers are named. Pass if the position can be revisited as product or market conditions change. [S4] [S8]

## Common failure modes and fixes

| Failure | Typical symptom | Fix |
| --- | --- | --- |
| Starting with a positioning statement | An elegant sentence contains assumed answers | Return to alternatives and analyze all five components before writing the explanation. [S2] [S4] |
| Treating a market map as buyer competition | Many similar products, little deal evidence | Keep the actual consideration set and current workflow; track future threats separately. [S3] |
| Listing features as value | The canvas says what exists but not why anyone chooses it | Add enabled actions, buyer consequences, and the alternative each chain beats. [S2] [S4] |
| Averaging all customers | A broad persona weakens every advantage | Identify the conditions shared by strong-value wins and compare separate segments. [S1] [S4] |
| Hiding an awkward attribute | A configurable product is pitched as effortless | Identify who values control, account for adoption effort, and exclude poor fit workflows. [S4] |
| Choosing a category to escape comparison | Familiar buyer expectations must repeatedly be corrected | Compare frames on truthful assumptions and visibility of current value. [S5] [S6] |
| Inventing a category too early | Buyers need a glossary before understanding the job | Test an existing category or meaningful subcategory first. [S2] [S6] |
| Overweighting losses | Team reports no differentiation despite ongoing wins | Investigate why suitable customers buy and whether losses reflect poor fit. [S1] |
| Substituting ambition for current value | The main argument depends on planned AI or expansion | Separate investor vision and describe the present offer. [S8] |
| Treating positive reactions as proof | Colleagues like the wording, but buyer choices remain unexplored | Check comprehension, real alternatives, value intensity, and disconfirming evidence. [S4] [S7] |
| Declaring permanent completion | No date or market-change trigger | Date the canvas and revisit when alternatives, capabilities, or expectations shift. [S4] |
