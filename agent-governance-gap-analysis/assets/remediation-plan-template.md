## Re-test

Re-run the gap analysis on {{DATE_PLUS_90}} and compare **all three counts** per dimension, not just the headline.

Progress runs unknown → not met → partial → met, and every step of that is real movement. A re-test where the headline held but several checks reached partial means controls now exist that didn't before — count it.
Test these three by attempting them, not by reading the config:

1. Offboarding — 24 hours after the next leaver, can their agent still reach anything?
2. Deny — deny a sensitive action and check the *target system's* logs for the request.
3. Attribution — pick one agent action from last week and trace it to a named human.
