# Public source register

Credit: Patrick Wind's public Full-Funnel Strategy and the named publishers below. All summaries are paraphrased. Research date: 2026-10-02.

Sources were downloaded with curl using redirects. Every numbered source returned HTTP 200 and its public body was inspected. Podcast and television entries contribute only their public descriptions, not unaccessed audio or paid episodes. The PDF was extracted with pdftotext; only Wind's own contribution is used for method details.

## Research limitations

The requested Domestika course landing page and its contents page returned HTTP 403 through curl. They are excluded from the numbered evidence register. Search surfaced its public syllabus, but this package does not use that as curl-fetched evidence. The linked Universidad Ecommerce original article returned HTTP 404; [S5] is the accessible episode description instead. No signup, private newsletter, paid lesson, authenticated LinkedIn content or third-party skill was accessed or copied. No public numerical case dataset was obtained, so case mentions and testimonials cannot support performance forecasts.

The older sources use different stage names. This package preserves those differences rather than claiming there is a single publicly documented canonical set of campaign settings. The German description uses the English method labels Full-Funnel Retargeting, Funnel Stage and Time Range; no distinct German method name was established. Marketing MasterMind is identity context, not evidence of a separate funnel formula. [S4][S6][S8]
