# Full-funnel plan template

Use one completed document per offer and market unless the business brief calls for a combined plan. Replace bracketed fields. Mark unknown, assumed and verified values explicitly. Remove guidance text only when the deliverable remains understandable. Cite public principles using the IDs in [sources.md](../references/sources.md); label other recommendations as implementation adaptations.
