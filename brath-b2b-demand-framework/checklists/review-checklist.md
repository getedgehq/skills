# Review checklist

Mark every item PASS or FAIL. A PASS requires evidence in the brief or an explicit unknown with a suitable learning action. A silent omission fails. This checklist operationalizes the cited method; it is not a checklist published by Martin Brath.

## Diagnosis and routing

- [ ] PASS / FAIL: The brief answers whether relevant buyers already search, with market and segment scope. [S1]
- [ ] PASS / FAIL: Search estimates, actual observations and unknowns are separated. [S4]
- [ ] PASS / FAIL: Low relevant volume is distinguished from absent relevant demand. [S1]
- [ ] PASS / FAIL: Brand, category, competitor and tangential intent are distinguished. [S1][S5]
- [ ] PASS / FAIL: The capture, education or combined branch follows the evidence, with uncertainty stated. [S1]
- [ ] PASS / FAIL: The recommendation identifies what evidence would change the selected branch. Package guidance.

## Channel design

- [ ] PASS / FAIL: Google Ads has an explicit capture job and SEO a justified organic role. [S1]
- [ ] PASS / FAIL: Paid-search learning informs SEO without claiming to validate all organic pages or messaging. [S4]
- [ ] PASS / FAIL: Unstable positioning or product-market fit limits large untested SEO commitments. [S1]
- [ ] PASS / FAIL: Social creative teaches the needed concept or builds recognizable preference, with a defined audience. [S2][S3]
- [ ] PASS / FAIL: LinkedIn selection is explained by audience and targeting usefulness. [S3]
- [ ] PASS / FAIL: Buying committees, sales model, geography and sales support affect the plan where relevant. [S2][S3]
- [ ] PASS / FAIL: Communication continues coherently through pages, retargeting and sales or product interactions. [S2]
- [ ] PASS / FAIL: Budget choices have contextual reasons rather than a claimed universal ratio. [S2]

## Measurement and attribution

- [ ] PASS / FAIL: Commercial outcomes go beyond lead counts, cheap clicks and traffic. [S2]
- [ ] PASS / FAIL: Education has appropriate diagnostics and is not evaluated only through immediate clicks. [S3]
- [ ] PASS / FAIL: Tracking represents completed actions and useful feedback from CRM or product systems is planned. [S6]
- [ ] PASS / FAIL: Proxy signals have a check against downstream outcomes. [S6]
- [ ] PASS / FAIL: Brand and non-brand reporting are separated; conversion credit is not called proof of demand creation. [S5]
- [ ] PASS / FAIL: Costs and sample limitations are disclosed fairly. [S5]
- [ ] PASS / FAIL: Experiments specify a question, owner, cap, review point and conditional next decision. Package guidance.

## Integrity and readiness

- [ ] PASS / FAIL: Source-backed claims resolve to fetched sources; added operating guidance is labelled.
- [ ] PASS / FAIL: Invented examples and modeling assumptions are clearly identified.
- [ ] PASS / FAIL: The brief does not promise results, attribute invented rules to Brath or imply endorsement.
- [ ] PASS / FAIL: The proposed plan stays within the task's authorization; producing a brief does not automatically launch ads.

A recommendation is ready when all applicable items pass. For a material unknown, the passing treatment is a provisional recommendation plus a concrete evidence plan, not an unsupported assertion.

## Common failure modes and fixes

| Failure | Why it fails | Fix |
| --- | --- | --- |
| Choose the cheapest CPC | Ignores channel job and intent | Start with search demand and buyer awareness |
| Reject search below an arbitrary volume | Discards potentially valuable scarce intent | Assess relevance and economics with sample caveats |
| Treat zero tool volume as proof | Confuses an estimate with market reality | Research buyer wording and verify accessible searches |
| Publish a large category SEO program before awareness exists | Assumes content alone will create category searches | Prioritize education; retain useful foundations |
| Bid broadly on problem terms to spend the budget | Pools weak intent with capture | Isolate exploratory queries and cap exposure |
| Require LinkedIn for every B2B product | Treats a platform label as strategy | Explain the actual targeting advantage |
| Run accurate targeting with generic creative | Access to buyers does not guarantee attention | Make the problem, category and brand understandable |
| Optimize for cheap forms or button clicks | Rewards activity that may lack commercial value | Verify real actions and follow downstream outcomes |
| Scale a proxy whose predictive value has weakened | Earlier activity can stop representing useful interest | Recheck its relationship to harder outcomes |
| Credit all organic conversions to SEO-created demand | Hides prior brand influence | Separate branded discovery and disclose attribution limits |
| Spread limited recognition spend worldwide | Reduces repetition in each market | Concentrate brand building while retaining useful capture |
| Declare failure after an early review with few searches | Confuses inadequate evidence with a reliable result | Review traffic fit early and commercial outcomes later |
| Promise identical results to an agency illustration | Transfers unsupported performance | Use contextual rules, not borrowed outcome promises |
