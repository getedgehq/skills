# Review checklist

Use PASS, FAIL or N/A for each item. Explain N/A briefly. A material FAIL means revise the plan or clearly label it conditional before handing it off. Planning does not itself authorize live account changes.

## Method and attribution

- [ ] PASS / FAIL: Credits Andrew Foxwell and distinguishes agency authors and community contributors where relevant.
- [ ] PASS / FAIL: Method claims point to fetched [S#] sources; no private membership content is implied.
- [ ] PASS / FAIL: Source heuristics, invented numbers and package adaptations are explicitly distinguished.
- [ ] PASS / FAIL: Examples are identified as invented illustrations, with no implied real client results.
- [ ] PASS / FAIL: Practitioner observations are not described as causal proof or performance guarantees.

## Decision fit

- [ ] PASS / FAIL: Recommendation considers budget, production volume, data density, predictability, risk and management capacity.
- [ ] PASS / FAIL: New concepts are distinguished from iterations; concepts and assets are counted separately.
- [ ] PASS / FAIL: Framework has an explicit learning or allocation job, trade-off and switch trigger.
- [ ] PASS / FAIL / N/A: A hybrid has separately funded lanes with distinct purposes.
- [ ] PASS / FAIL: Missing inputs remain visible; the plan does not fabricate account history.

## Economics and exposure

- [ ] PASS / FAIL: Affordable acquisition cost is supported by margin arithmetic and explicit payback assumptions.
- [ ] PASS / FAIL: Daily lane allocations fit the total; CBO minimums fit inside their campaign allocation.
- [ ] PASS / FAIL: Planned duration and outlay fit the allowance, including production cost where relevant.
- [ ] PASS / FAIL: Review accounts for conversion delay, attribution basis and observed exposure.
- [ ] PASS / FAIL: Ad-set budget protection is not confused with equal individual-ad delivery.
- [ ] PASS / FAIL: Maximum-loss rule, monitoring owner and action are specified as local operating choices.
- [ ] PASS / FAIL / N/A: Bid-control type is named and no hard realized-CPA guarantee is claimed.

## Creative quality and Yappers

- [ ] PASS / FAIL: Each brief has specific customer evidence, a meaningful hypothesis and a plausible route to sales.
- [ ] PASS / FAIL: Visual diversification preserves the winning psychology while changing entry points.
- [ ] PASS / FAIL: Quality is not reduced to output quotas, polished production or cosmetic variants.
- [ ] PASS / FAIL: Claims, endorsements and customer experiences are supported or explicitly pending verification.
- [ ] PASS / FAIL / N/A: Yapper has a relevant hook, concrete lived problem, natural product bridge and gentle invitation.
- [ ] PASS / FAIL / N/A: Yapper execution is conversational and single take, with no forced commercial delivery or early product pitch.
- [ ] PASS / FAIL / N/A: Proposed scripts require truthful speaker validation; no fabricated testimonial is presented as genuine.
- [ ] PASS / FAIL: AI supports execution and refinement while specific research and human QA remain in the workflow.

## Evaluation and scaling

- [ ] PASS / FAIL: Efficiency and spend capacity are both considered; attention metrics are diagnostic.
- [ ] PASS / FAIL: Insufficient exposure is distinguished from failure and relative improvement from economic qualification.
- [ ] PASS / FAIL: A testing winner has a destination-validation plan and fallback if delivery disappears.
- [ ] PASS / FAIL: Concentration is monitored without automatically disabling the strongest ad.
- [ ] PASS / FAIL: Acquisition is measured separately from warm-audience harvesting where data allows.
- [ ] PASS / FAIL: Next actions have owners, dates and evidence-based triggers, within applicable authorization.

## Common failure modes and fixes

| Failure | Fix |
|---|---|
| Choosing a framework because a popular account uses it | Re-score against the actual budget, output, data and risk constraints. |
| Funding twenty separate tests with a tiny budget | Reduce simultaneous briefs or use a consolidated route with explicit evidence limits. |
| Describing CBO minimums as equal asset exposure | Describe ad-set-level funding and inspect actual asset delivery. |
| Calling direct testing loss-free | Add monitoring for sudden spend and an agreed maximum loss. |
| Calling any cap-delivering ad profitable | Check realized cost, customer quality and contribution; verify control mechanics. |
| Declaring a winner after a week with almost no events | Extend only if affordable, or label insufficient exposure. |
| Picking the highest ROAS on two purchases | Compare conversion volume, acquisition cost and sustained spend capacity. |
| Treating a better but unprofitable ad as scale-ready | Mark relative improvement and keep further work bounded. |
| Writing a generic Yapper about everyone needing the product | Anchor it in a specific truthful moment and delay the product bridge. |
| Turning a Yapper into a studio montage | Record conversational single takes or label the montage as a different format. |
| Raising volume by changing background colors | Add different persuasive formats and researched situations. |
| Inventing an authority claim to amplify emotion | Use supported proof or a pending research field. |
| Relying on one creative for nearly all delivery | Retain the winner while developing alternate formats of its working angle. |
| Assuming graduation preserves test performance | Validate results and allocation in the destination; retain a bounded fallback. |
| Mistaking retargeting revenue for acquisition growth | Review first-time customer revenue and new-customer cost. |
| Keeping a method that stopped producing useful winners | Compare another structure with an affordable period, criterion and stopping rule. |
