# Review checklist

Evaluate the deliverable against [method.md](../references/method.md). Mark each item PASS or FAIL with evidence. Any unresolved essential item makes the plan a draft and blocks the affected verdict or action, not all independent production planning. Mark a conditional item not applicable only with an explicit reason.

## Pass/fail criteria

- [ ] PASS / FAIL: Facts, assumptions, source-backed principles, and account decisions are distinguishable.
- [ ] PASS / FAIL: Claims about the method cite a fetched source and do not misattribute Roxana's supporting guidance to Denys.
- [ ] PASS / FAIL: No invented universal budget split, conversion floor, CPA target, stop-loss multiple, or scaling formula is presented as published method.
- [ ] PASS / FAIL: Product, offer, primary outcome, commercial target, and measurement source are specified, or their absence explicitly blocks the relevant decision.
- [ ] PASS / FAIL: Attribution maturation and tracking limitations are visible before winner selection.
- [ ] PASS / FAIL: Exploration and Iteration are distinct; an iteration names an evidenced parent winner.
- [ ] PASS / FAIL: Where no winner exists, the plan prioritizes discovery and includes a conditional iteration follow-up.
- [ ] PASS / FAIL: Hypotheses identify a customer situation, expected response, and reason, with a useful priority order.
- [ ] PASS / FAIL: Cosmetic exports and hook edits do not inflate substantive concept diversity.
- [ ] PASS / FAIL: The 8 to 12 inventory guideline and weekly 3 to 5 variant guideline are correctly distinguished and any adjustment is explained.
- [ ] PASS / FAIL: Volume and concurrent testing are feasible within production capacity and useful-signal budget.
- [ ] PASS / FAIL: Every test identifies its learning unit, changed variables, constants, and inference limits.
- [ ] PASS / FAIL: Iteration prioritizes the hook before minor polish unless a documented account reason supports another lever.
- [ ] PASS / FAIL: Each brief has one angle, a concrete opening, a structure, and creator freedom.
- [ ] PASS / FAIL: Testimonials, demonstrations, and product claims have real evidence or are marked pending.
- [ ] PASS / FAIL: Review rules exist before launch and distinguish performance failure from insufficient evidence.
- [ ] PASS / FAIL: Spending boundaries have an explicit consequence and are not exceeded through an open-ended retest.
- [ ] PASS / FAIL: Borderline follow-ups have a question, owner, date, and cap; low delivery is not automatically a loser.
- [ ] PASS / FAIL: Fatigue interpretation combines CPM with frequency, CTR, and market or setup changes.
- [ ] PASS / FAIL: MER and profit context inform business decisions without pretending to attribute a result to one hook.
- [ ] PASS / FAIL: The learning log connects findings to named next-wave briefs, owners, and dates.
- [ ] PASS / FAIL: Campaign edits and spending actions remain within the user's actual authorization.

## Common failure modes and fixes

| Failure | Why it fails | Fix |
| --- | --- | --- |
| Twelve color variants called twelve concepts | Production count substitutes for substantive diversity | Count the original concept once; create different messages or situations |
| New audiences, offers, creators, and hooks changed together | The claimed isolated learning is unsupported | Label a concept package or redesign a one-lever comparison |
| Iteration of an asset with no valid winning evidence | Refinement assumes what exploration should discover | Mark unproven and return it to discovery |
| Tiny sample declared a winner | Noise is treated as signal | Apply the account's evidence and maturation gates; mark inconclusive if unmet |
| CTR winner scaled despite expensive purchases | Attention replaces the actual commercial objective | Keep CTR diagnostic and decide using the primary outcome plus economics |
| Every rising CPM triggers a pause | A warning is mistaken for a verdict | Review frequency, CTR, external changes, and outcome evidence together |
| Exact weekly quota despite inadequate budget | Every asset becomes under-delivered | Reduce concurrency and explain the volume adjustment |
| Creator told every syllable | Authentic expression is removed | Specify opening, structure, claims, and freedom separately |
| Retest continues indefinitely | Ambiguity consumes the budget | Define one bounded follow-up and an unresolved outcome if it remains ambiguous |
| Case-study ROAS target exported to all brands | Brand-specific economics become a false universal rule | Derive the target from the actual account |
| Higher MER claimed to prove one new hook worked | An aggregate metric is used for ad-level attribution | Report MER as business context and limit claims to the actual comparison |
| Source context presented as an experiment | Marketing reports or episode summaries imply causal proof | Identify publisher, evidence type, and limitations |
