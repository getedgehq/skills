# Pass/fail review checklist

For each applicable item, record **PASS** or **FAIL**, evidence, and a fix owner. Use **N/A with reason** only when the assignment legitimately excludes that item. A complete blueprint should have no unresolved failures affecting credibility, the primary objective, feasibility, or measurement. Read [method.md](../references/method.md) for rationale.

| Check | PASS condition | FAIL condition |
| --- | --- | --- |
| Attribution | Public method credited; official affiliation not implied | Package presents itself as Gahan's internal or endorsed process |
| Evidence levels | Direct statements, publisher interpretation, and package adaptations distinguished | Added scoring, scripts, thresholds, or statistical rules attributed to Gahan |
| Buyer grounding | Specific roles, tension, and evidence or labeled hypothesis | Audience described only as businesses or decision-makers |
| Product truth | Material claims verified and bounded | Invented uniqueness, guaranteed outcomes, or fictional testimonials |
| Goal focus | One primary objective with definition and date | Equal priority assigned to every funnel outcome |
| Concept value | Audience receives useful insight or a substantive resource | Only slogans or a repackaged brochure |
| Creator authority | Relevant expertise supported by public work or verified experience | Selection justified by fame or follower total alone |
| Audience fit | Evidence supplied or inference and gaps stated | Demographics invented or tool score treated as proof |
| Human alignment | Conversation confirms interest, honest viewpoint, and availability, or pending status is explicit | Excitement and product experience assumed |
| Brief quality | Goal, audience, evidence, deliverables, boundaries, and logistics clear | Rigid script with unsupported proof points |
| Human video | Expert contributes judgment, evidence, and an appropriate next step | Creator recites generic brand copy |
| Commercial feasibility | Cost ceiling includes applicable fees, production, rights, media, and measurement | Paid scope unfunded or rights assumed |
| Distribution | Relevant targeting, current eligibility check, and permissions specified | Historical tool mentions treated as current instructions |
| Disclosure | Paid relationship clearly identified and implementation requirements checked | Hidden sponsorship or assumed endorsement |
| Measurement | Primary outcome, collection method, quality, spend, and review window defined | Raw reach or clicks treated as proof of trust or revenue |
| Comparison quality | Exposure differences and attribution limits considered | More paid spend mistaken for a better creator |
| Optimization | Criteria for scale, revise, hold, and stop stated | Automatic scaling from a noisy early spike |
| Evidence hygiene | Historical and vendor claims contextualized; illustrations labeled | Reported uplift reused as a guarantee or example data called observed |
| Authorization | Drafts prepared within scope; actual actions match user authorization | Planning request interpreted as outreach or spending permission |
| Handoff | Next decision, owner or required role, and date recorded | Strategy ends without a usable next action |

## Common failure modes and fixes

| Failure mode | Fix |
| --- | --- |
| Famous creator, wrong profession | Return to category authority and buyer evidence; replace or hold the candidate |
| Useful expert, weak audience data | Request available analytics and mark inference; bound any evidence-gathering test |
| No genuine interest | Rework the concept or select another creator rather than buying scripted enthusiasm |
| No product experience | Offer evaluation time; use factual explanation until genuine experience exists |
| Several goals in one brief | Choose one primary buyer response and move other needs to separate activations |
| Creator is merely a promotional face | Have them help build the resource, interpretation, or demonstration |
| Corporate script removes personality | Keep factual constraints, release the language and story structure to the creator |
| Unsupported performance claim | Narrow to verified capability, provide evidence, or remove the assertion |
| Every video demands a demo | Match the next step to the chosen objective and buyer readiness |
| Large totals hide poor efficiency | Report spend, qualified outcomes, media efficiency, and total campaign cost together |
| Small sample treated as decisive | Extend the agreed observation window or hold the decision with uncertainty stated |
| Paid amplification unavailable | Use an authorized alternative and revise reach expectations and economics |
| Trust reduced to engagement | Add appropriate buyer or brand evidence; call engagement a proxy |
| Vendor scores treated as universal truth | Review underlying content, audience evidence, and human alignment |
| Source count treated as independent proof | Note shared research and publisher commercial interests |
| Invented results in the case for investment | Replace with labeled scenarios or observed client evidence |
