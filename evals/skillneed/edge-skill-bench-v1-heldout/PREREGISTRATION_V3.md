# SkillNeed held-out v3 preregistration

The v2 successor was stopped after 11 of 54 executor attempts and before judging because the v1 judge revealed that “exact GetEdge command” was underspecified in the rubric. Those attempts remain retained, are excluded from efficacy, and are not pooled.

V3 freezes the same six unseen scenarios, the revised Skill package, and semantic checkers, with three changes made before inspecting any v2 final response: every recommendation rubric now contains the literal accepted install command; the Skill must return only the decision; and it may not perform the underlying task. All other executor, judge, sample, arm, blinding, cap, and uncertainty settings remain unchanged.
