# Hacker News submission

## Title

Show HN: QuietQueue – a local-first reading queue for the macOS menu bar

## Text

QuietQueue 0.3.0 is a macOS menu bar app with a deliberately narrow workflow: save a URL from the clipboard, tag saved links locally, and export the queue as JSON.

It is currently an unsigned beta. There are no accounts, no cloud sync, and no browser extension. The repository does not document public benchmark results or a distribution channel.

I am sharing the exact current scope because the project is early. Feedback on the local-first model, clipboard capture, and export format would be useful.
