# QuietQueue launch asset brief

## Objective

Show one concrete QuietQueue 0.3.0 workflow: a URL moves from the clipboard into a locally tagged reading queue, with JSON export available as the final action.

## Recommended capture

Create one real-product screenshot after a working build is available. Frame the macOS menu bar and the open QuietQueue panel. The panel should show a saved URL, a visible local tag, and the JSON export control if those elements can appear together in the actual interface.

Do not fabricate interface elements or composite a mock product screen. The repository currently contains no screenshots or video, so no launch visual can be claimed as captured yet.

## Optional three-step capture sequence

1. A URL present in the clipboard immediately before it is saved.
2. The saved link in QuietQueue with a local tag applied.
3. The real JSON export result, with any private data removed.
