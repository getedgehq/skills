# Product Hunt listing

## Name

QuietQueue

## Tagline

A local-first reading queue in your macOS menu bar

## Description

QuietQueue keeps a focused list of links for later on your Mac. Save a URL from the clipboard, organize saved links with local tags, and export the queue as JSON.

Version 0.3.0 is an unsigned beta. There are no accounts, no cloud sync, and no browser extension. A distribution channel is not documented in the repository.

## First comment

QuietQueue starts from a deliberately compact workflow: a URL is already on your clipboard, you save it to the queue, and you can tag or export it when useful.

The current build is a macOS menu bar app and remains an unsigned beta. The three capabilities listed above are the full verified feature set in the repository today.
