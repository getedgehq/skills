# LinkedIn launch post

Introducing QuietQueue 0.3.0, a local-first macOS menu bar app for keeping a focused reading queue.

The current beta deliberately has a small scope:

- Save a URL from the clipboard
- Add tags stored locally
- Export the queue as JSON

QuietQueue is currently an unsigned beta. It does not include accounts, cloud sync, or a browser extension. The repository also does not document a distribution channel or public performance results.

This release is for people who prefer a simple, local workflow for collecting links rather than a connected reading service.
