# Show HN: QuietQueue – a local-first reading queue for the macOS menu bar

QuietQueue 0.3.0 is a small macOS menu-bar app for saving links to revisit later.

The implemented scope is narrow: save a URL from the clipboard, tag saved links locally, and export the queue as JSON. There is no account system, cloud synchronization, or browser add-on.

It is currently an unsigned beta. I’m sharing the scope plainly because I’d like feedback on the core interaction: is clipboard-to-queue capture useful on its own, and is JSON the right escape hatch for a local reading list?
