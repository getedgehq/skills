# Product name

QuietQueue

# Tagline

A local-first reading queue in your macOS menu bar

# Description

QuietQueue stores links for later and opens them in a focused reading queue. Save a URL from the clipboard, organize saved links with local tags, and export the queue as JSON.

# What it supports today

- Saving a URL from the clipboard
- Tagging saved links locally
- Exporting the queue as JSON

# Release note

QuietQueue is an unsigned beta. It has no accounts, cloud sync, or browser extension.

# Maker comment

QuietQueue is built around a narrow, local-first workflow: capture a link, tag it, and return to it in a focused queue. The JSON export keeps the saved queue portable. This beta is intentionally limited, and the current boundaries are stated above so people know exactly what is—and is not—available.
