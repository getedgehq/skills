# Title

Show HN: QuietQueue – a local-first reading queue for the macOS menu bar

# Text

QuietQueue is a small macOS menu bar app for storing links to read later.

The implemented workflow is deliberately narrow: save a URL from the clipboard, add local tags, and export the queue as JSON. Saved links can then be opened in a focused reading queue.

It is currently an unsigned beta. There are no accounts, no cloud sync, and no browser extension.

I’d be interested in feedback on whether this minimal capture-and-export workflow is useful and where it feels incomplete.
