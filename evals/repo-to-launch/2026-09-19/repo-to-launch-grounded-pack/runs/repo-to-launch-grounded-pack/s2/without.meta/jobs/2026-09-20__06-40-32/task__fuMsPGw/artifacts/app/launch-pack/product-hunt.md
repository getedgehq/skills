# QuietQueue

## Tagline

A local-first reading queue in your macOS menu bar

## Short description

Save a URL from the clipboard, organize saved links with local tags, and export the queue as JSON.

## Maker note

QuietQueue 0.3.0 keeps link-saving intentionally small and local-first. It is a macOS menu bar app for collecting links to read later and opening them in a focused reading queue.

The current verified feature set is clipboard URL saving, local tagging, and JSON export.

QuietQueue is an unsigned beta. It does not currently include accounts, cloud sync, or a browser extension. Public benchmark results are not available.
