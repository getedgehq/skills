# Product name

QuietQueue

# Tagline

A local-first reading queue in your macOS menu bar

# Description

QuietQueue stores links for later and opens them in a focused reading queue. Save a URL from the clipboard, tag saved links locally, and export the queue as JSON.

# First comment

QuietQueue 0.3.0 is a deliberately compact, local-first macOS menu bar app.

The current workflow covers clipboard URL capture, local tagging, and JSON export. This release is an unsigned beta. It has no accounts, cloud sync, or browser extension, and no public benchmark results are available.

That is the complete scope of the current repository-backed release.
