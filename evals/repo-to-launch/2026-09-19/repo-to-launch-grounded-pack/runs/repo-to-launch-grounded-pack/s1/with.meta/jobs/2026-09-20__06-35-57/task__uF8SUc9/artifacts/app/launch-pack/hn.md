# Title

Show HN: QuietQueue – a local-first macOS menu bar reading queue

# Text

QuietQueue 0.3.0 stores links for later and opens them in a focused reading queue.

The current implementation supports three actions: save a URL from the clipboard, tag saved links locally, and export the queue as JSON.

It is an unsigned beta. It has no accounts, cloud sync, or browser extension. There are also no public benchmark results. The repository currently documents this intentionally limited scope.
