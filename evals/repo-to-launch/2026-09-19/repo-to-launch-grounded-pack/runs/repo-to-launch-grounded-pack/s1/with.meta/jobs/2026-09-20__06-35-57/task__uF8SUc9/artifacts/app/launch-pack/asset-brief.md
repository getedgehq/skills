# QuietQueue launch asset brief

## Evidence constraint

The repository contains no screenshots or video. Do not present a mockup as a real product capture and do not imply unverified interface details.

## Recommended primary asset

Create a text-led 1200 × 630 launch card rather than a fabricated app screenshot.

- Product name: QuietQueue
- Headline: “A local-first reading queue for macOS”
- Supporting line: “Clipboard URLs · Local tags · JSON export”
- Status label: “0.3.0 · Unsigned beta”
- Visual direction: quiet, editorial, restrained; use simple typography and abstract queue/link motifs only
- Avoid: interface chrome, fabricated menus, third-party logos, usage metrics, rating badges, download claims, or feature icons that imply more than the three verified capabilities

## Real capture plan

If a runnable build becomes available, replace or supplement the launch card with real captures showing only:

1. Saving a URL from the clipboard
2. Applying a local tag to a saved link
3. Exporting the queue as JSON

Keep the macOS menu bar context visible where practical. Label the build as an unsigned beta. Review every capture for private URLs, tags, filenames, notifications, and account information before publishing.

## Alt text

“QuietQueue launch card describing a local-first macOS reading queue with clipboard URL saving, local tags, and JSON export; version 0.3.0 unsigned beta.”
