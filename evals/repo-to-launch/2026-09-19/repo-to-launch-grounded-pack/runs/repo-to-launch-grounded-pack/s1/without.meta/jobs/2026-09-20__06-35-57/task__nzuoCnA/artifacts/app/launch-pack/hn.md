# Show HN: QuietQueue – a local-first reading queue for the macOS menu bar

QuietQueue 0.3.0 stores links for later and opens them in a focused reading queue. It is a macOS menu bar app with a deliberately small feature set:

- save a URL from the clipboard;
- tag saved links locally;
- export the queue as JSON.

It is currently an unsigned beta. There are no accounts, cloud sync, or browser extension, so it should be understood as a local-first, single-Mac tool in its present form.

I’m interested in technical and workflow feedback on this minimal scope, particularly clipboard capture, local organization, and JSON export.
