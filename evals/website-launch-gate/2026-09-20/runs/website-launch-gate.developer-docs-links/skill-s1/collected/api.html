API reference

The core builder methods for declaring a Flux event workflow.

workflow(name)

Creates a named workflow builder. Names should be stable and unique within an application.

const flow = workflow("welcome");

Parameters

name: string — a human-readable workflow identifier.

.on(event)

Sets the event that starts the workflow.

flow.on("user.created");

Parameters

event: string — the event name emitted by your application.

.step(name, handler)

Adds a named handler to the workflow. Steps execute in declaration order.

flow.step("send-email", sendWelcome);

Parameters

name: string — a stable step identifier.
handler: function — the function that performs the step.
