Guide

Build your first workflow

Connect an application event to a sequence of clear, named steps.

Install the SDK

Add Flux to your project with your package manager.

npm install flux

Define a workflow

Create a builder, choose its trigger, and add the work that should happen next.

import { workflow } from "flux";

export const welcome = workflow("welcome")
  .on("user.created")
  .step("send-email", sendWelcome);
Keep names stable. Workflow and step names make the flow understandable when you inspect it later.
