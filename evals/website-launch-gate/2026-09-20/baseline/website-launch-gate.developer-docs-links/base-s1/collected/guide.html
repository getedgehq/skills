Build your first workflow

Connect an event to a handler in three small steps.

01

Install the SDK

npm install @flux/sdk
02

Create a workflow

import { createFlux } from "@flux/sdk";

const flux = createFlux();

flux.on("order.created", async (event) => {
  await fulfill(event.order);
});
03

Emit the event

await flux.emit("order.created", { order });

Your handler receives the payload and runs the next step in the workflow.
