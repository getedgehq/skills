API reference

The core surface for defining and running event workflows.

createFlux(options?)

Creates a Flux instance. Pass an optional configuration object for application-specific settings.

const flux = createFlux();

flux.on(name, handler)

Registers an asynchronous handler for an event name.

flux.on("order.created", async (event) => {
  await fulfill(event.order);
});

flux.emit(name, payload)

Emits an event with its payload and returns a promise that resolves when the workflow is complete.

await flux.emit("order.created", { order });
