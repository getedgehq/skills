Reference

API reference

The small set of primitives used to create and dispatch Flux event workflows.

Client

FluxClient

Create a client before emitting events or defining workflows.

const flux = new FluxClient({
  apiKey: process.env.FLUX_API_KEY
});
Keep credentials server-side. Load API keys from your environment and do not embed them in browser code.

Method

flux.emit(name, payload)

Dispatch an event with a name and a JSON-serializable payload.

ParameterTypeDescription
namestringThe event name.
payloadobjectData sent with the event.

Method

flux.workflow(name, handler)

Define the work that should run when a named event is received.

flux.workflow("order.created", async (event) => {
  return normalizeOrder(event.payload);
});

Handling failures

Errors

Client methods reject with an Error when a request cannot be completed. Wrap awaited calls in your application’s normal error boundary.
