Guide · 5 minute setup

Build your first workflow

Install Flux, initialize a client, and send your first event.

Step 01

Install the SDK

Add Flux to your project with your package manager.

npm install @flux/sdk

Step 02

Configure the client

Import the client and initialize it with an environment variable.

import { FluxClient } from "@flux/sdk";

const flux = new FluxClient({
  apiKey: process.env.FLUX_API_KEY
});
Before you run this: add FLUX_API_KEY to your server environment.

Step 03

Send an event

Give the event a clear name and include only the data the workflow needs.

await flux.emit("order.created", {
  orderId: "ord_123",
  total: 4200
});

You’re ready
