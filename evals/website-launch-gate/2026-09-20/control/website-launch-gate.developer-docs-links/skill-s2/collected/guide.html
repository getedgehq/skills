Build your first workflow

Go from installation to an event-driven workflow in three short steps.

Step 01

Install the SDK

npm install @flux/sdk

Step 02

Configure the client

Load your API key from the environment and create a client.

import { Flux } from "@flux/sdk";

const flux = new Flux({
  apiKey: process.env.FLUX_API_KEY
});

Step 03

Define and trigger

Register the work, then emit an event whenever it should run.

flux.workflow("order.received", async (event) => {
  await prepareOrder(event.data);
});

await flux.emit("order.received", {
  orderId: "ord_123"
});
Before you ship: store the API key in your deployment environment and keep it out of client-side code.
