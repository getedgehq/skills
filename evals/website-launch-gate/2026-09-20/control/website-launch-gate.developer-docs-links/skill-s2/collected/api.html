API reference

The small surface area you need to define and trigger event workflows.

Client

Create a Flux client with the configuration for your environment.

import { Flux } from "@flux/sdk";

const flux = new Flux({
  apiKey: process.env.FLUX_API_KEY
});

workflow(name, handler)

Registers a named workflow and the handler that should run when it is triggered.

flux.workflow("order.received", async (event) => {
  await prepareOrder(event.data);
});

emit(name, data)

Emits an event with a serializable payload.

await flux.emit("order.received", {
  orderId: "ord_123"
});
Keep secrets server-side. Never expose API keys in browser code or commit them to source control.
