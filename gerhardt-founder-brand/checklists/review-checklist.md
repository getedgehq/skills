# Founder-brand review checklist

This checklist operationalizes the method; it is not an expert-authored scorecard. Mark each applicable item PASS or FAIL and record evidence. Use N/A only when a section is outside the requested deliverable, such as a publishing schedule for a standalone post. Any failure affecting factual accuracy, the core story, or the product promise must be repaired before calling content ready.

## Pass/fail gates

- [ ] **Audience:** A specific customer and useful problem are identifiable. PASS if the reader can tell who benefits; FAIL if the audience is everyone. [S1] [S2]
- [ ] **Authentic input:** Founder experiences and beliefs come from available material. PASS if provenance is recorded; FAIL if the editor invented a memory, credential, or opinion. [S2] [S4]
- [ ] **Participation:** Capture and review fit the founder's willingness and capacity. PASS if participation is concrete; FAIL if the plan depends on unavailable involvement. [S1]
- [ ] **Niche:** The founder has a recognizable area of business-relevant expertise. PASS if topics reinforce it; FAIL if unrelated interests dominate. [S3]
- [ ] **Story:** Backstory, problem, reason for building, and customer improvement connect. PASS if the chain is specific; FAIL if it is a generic passion statement. [S2]
- [ ] **Villain:** The obstacle is recognizable and relevant. PASS if overcoming it connects to the solution; FAIL if it is gratuitous hostility or invented drama. [S2]
- [ ] **Beliefs:** Positions have supporting observations and useful implications. PASS if they change a decision; FAIL if they merely declare ambition. [S1]
- [ ] **Product alignment:** Promises match actual capability and distinguish plans from facts. PASS if limits are visible; FAIL if story and product contradict each other. [S1]
- [ ] **Distribution:** Channel choice follows audience evidence and existing ingredients. PASS if the rationale is stated; FAIL if historical success is treated as a universal playbook. [S1] [S5]
- [ ] **Audience benefit:** People gain something beyond company promotion. PASS if that benefit is explicit; FAIL if the series or community is mostly announcements. [S1] [S2]
- [ ] **Founder voice:** The draft preserves this person's thinking and concrete detail. PASS if the founder can recognize the argument; FAIL if generic executive or AI prose replaces it. [S4]
- [ ] **Cadence:** Frequency fits capacity and material quality. PASS if responsibilities are feasible; FAIL if volume is the strategy or timing is sold as a guarantee. [S1] [S4]
- [ ] **Feedback:** Relevant signals lead to a proportionate next decision. PASS if audience needs are interpreted; FAIL if all reactions count equally or comments dictate strategy. [S2] [S3]
- [ ] **Measurement:** Reach is paired with trust and business-interest evidence. PASS if uncertainty is stated; FAIL if likes alone prove success or correlation is called revenue causation. [S1]
- [ ] **Delivery:** Missing facts are visible and requested scope is satisfied. PASS if the user can act on the result; FAIL if unsupported fields appear as publication-ready facts. This is a package quality gate.

## Common failure modes and fixes

| Failure mode | Fix | Principle |
| --- | --- | --- |
| Polished biography with no buyer connection | Rebuild around an experienced customer problem and reason for starting | [S2] |
| Personality replaces expertise | Restore the niche; keep personal texture where it helps connection | [S2] [S3] |
| Generic opinions and invented founder stories | Obtain a concrete incident or voice note; leave unanswered facts open | [S2] [S4] |
| Dramatic villain unrelated to the product | Choose a real obstacle the company can address | [S2] |
| Promise exceeds product behavior | Narrow the claim or label the future direction clearly | [S1] |
| Awards, links, and webinars dominate drafts | Extract a useful lesson and explain its customer implication | [S1] |
| Founder dislikes the imposed format | Try writing or an interview instead of solo recording | [S2] |
| Marketer or AI manufactures the persona | Ground drafting in recurring founder inputs and a source-based voice guide | [S4] |
| Daily posting plan without enough ideas | Reduce cadence and invest in capture before filling slots | [S1] |
| Mandatory LinkedIn or old platform tactics | Recheck buyer attention and current response in the founder's context | [S5] |
| New community with only promotional updates | Define member benefit; use existing audience channels if a group adds no value | [S2] [S5] |
| Popular content from irrelevant viewers drives strategy | Segment signals by audience relevance and inspect buyer questions | [S2] |
| Every idea must be new | Refresh a strong older idea or adapt it into a useful longer asset | [S3] |
| Comments automatically become roadmap instructions | Treat feedback as evidence alongside judgment and other customer insight | [S2] |
| No immediate pipeline triggers abandonment | Inspect relevance, quality, and inbound evidence across a realistic review interval | [S1] [S2] |
| Likes are reported as commercial return | Add qualified discovery mentions and trust evidence; retain attribution uncertainty | [S1] |

## Repair order

Repair invented facts and unsupported promises first. Then check audience, story, beliefs, and voice. Finally adjust channel, cadence, feedback, and measurement. Do not solve a weak premise by producing more drafts. Reapply the relevant gates after changes and deliver a concise note on any unresolved inputs.
