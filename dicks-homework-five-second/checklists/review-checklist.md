# Review checklist

Review only the requested output mode. Mark each applicable item **PASS** or **FAIL**; use **N/A** for another mode. A failed factual or change criterion blocks presenting a draft as a finished true story. A memory cue can pass without becoming a story.

## Capture review

- [ ] **Dated and retrievable:** Each entry has a capture date and enough information for the owner to recover the moment. [S2][S4]
- [ ] **Brief:** Entries use fragments or a few sentences rather than a full daily report. [S2][S4]
- [ ] **Ordinary moments allowed:** Quiet material is retained without requiring spectacle or a finished revelation. [S2][S3]
- [ ] **Older memories labelled:** Recalled earlier events cannot be mistaken for today's events; uncertain dates remain uncertain. [S4]
- [ ] **Requested scope met:** Capture-only work supplies useful cues and a reusable prompt without demanding a full story worksheet. This is a package adaptation.

## Story selection and draft review

- [ ] **Supported change:** The narrator's before and after can be stated clearly using supplied or confirmed experience. [S3][S5]
- [ ] **Specific turn:** An identifiable event, observation, exchange, or thought connects those states; a vague moral is insufficient. [S3][S5]
- [ ] **One principal destination:** Selected details clarify the chosen turn rather than competing lessons. [S3][S5]
- [ ] **Relevant opening:** The opening shows the prior state or an approximate opposite and starts near enough to the turn to avoid unnecessary history. [S3][S4]
- [ ] **Scene underway:** Action and a recognizable place orient the audience; background arrives when needed. [S3][S4][S5]
- [ ] **Live question:** Major beats give the audience a real hope, concern, uncertainty, or plan to follow. [S3][S5]
- [ ] **Necessary detail:** Removing any retained substantial detail would weaken comprehension, stakes, or the turn. [S3]
- [ ] **Proportionate ending:** The change is clear near the ending and the story does not inflate a small shift into unsupported lifelong transformation. [S3][S5]
- [ ] **Suitable length and voice:** The draft respects the user's format and limit; present tense is considered for oral telling, not imposed universally. [S3][S4]

## Factual and delivery review

- [ ] **No fabricated additions:** Actions, sensations, thoughts, outcomes, dialogue, and other people's motives come from the owner or remain unresolved. Dicks's non-invention rule supports this package safeguard. [S3]
- [ ] **Compression preserves meaning:** Omissions do not misrepresent consequential timing, causality, or attribution. The package's conservative compression rule is explicit in [method.md](../references/method.md). [S3]
- [ ] **Correct status:** Material lacking a supported change is delivered as a cue, anecdote, or candidate needing detail. [S3]
- [ ] **Notes separated:** Questions and editorial analysis remain outside the audience-facing story; unresolved factual gaps are disclosed. This is a package adaptation.
- [ ] **Illustrations labelled:** Invented examples are not presented as the user's memories or Dicks's experiences. This is a package adaptation.

## Common failure modes and fixes

| Failure | What reveals it | Repair |
| --- | --- | --- |
| Waiting for spectacle | Quiet days are empty or discarded. | Save a small distinctive moment before assessing story potential. [S2][S3] |
| Diary-sized capture | Nightly entries become extensive accounts. | Reduce to dated retrieval cues; move drafting to a separate task. [S4] |
| Event report mistaken for story | The draft lists activities but the narrator is unchanged. | Ask for the inner shift; otherwise keep an anecdote. [S3] |
| Forced epiphany | The lesson exceeds what the owner remembers. | Remove the unsupported claim; retain the moment or seek clarification. [S3] |
| Background-heavy opening | The first paragraph explains family, career, or history. | Begin with the nearest useful action; insert context when needed. [S3][S5] |
| Manufactured opposite | The opening exaggerates an earlier belief. | Use the true prior state, even if only an approximate contrast. [S3] |
| Flat middle | The audience knows each next event and has no reason to care. | Clarify the narrator's actual hope, fear, or plan; cut redundant beats. [S3][S5] |
| Decorative detail overload | Furnishings, clothes, or tool names crowd out the event. | Keep recognizable nouns and only specifics that affect the story. [S4] |
| Added drama | Unverified dialogue or peril supplies the tension. | Restore supported material and repair selection or pacing. [S3] |
| Long moral after the turn | Several closing sentences repeat a lesson. | Stop after the new understanding is legible; retain necessary aftermath. [S3][S5] |
| Rigid five-minute format | A short memory is padded for stage length. | Match the actual setting and material; shorten without losing the change. [S3] |
| Confused memory timeline | A childhood incident appears to happen on the capture date. | Add a recalled-memory label and approximate event age if known. [S4] |

## Completion rule

Repair applicable failures before delivering a finished story. If an answer from the owner is essential, deliver the supported cue, candidate analysis, or working outline and identify the missing fact. Do not iterate by inventing material. Once the output meets its mode's criteria and the requested scope, deliver it without demanding extra development.
