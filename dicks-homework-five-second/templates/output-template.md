# Output template

Use only the sections the user needs. The daily bank should stay small; the story worksheet belongs to development, not mandatory nightly capture. The fields are this package's implementation of Dicks's public method. [S2][S3][S4][S5]

## A. Daily story bank

**Daily prompt:** Look back over today. Which moment would you choose to tell someone about, even if it seems small?

| Capture date | Moment cue |
| --- | --- |
| [YYYY-MM-DD] | [Place or situation; distinctive action, exchange, thought, or feeling; enough to retrieve the experience.] |
| [YYYY-MM-DD] | [Recalled memory: approximate event date or age; retrieval cue. Mark uncertainty.] |

### Field guidance

- **Capture date:** Use the date reviewed or recorded, keeping it distinct from an older event's date. Do not invent dates to fill gaps.
- **Moment cue:** Use fragments or a few sentences. Include the person and place when they make the memory recognizable. Save more than one row when appropriate, without expanding into a full diary. [S2][S4]
- **Recalled memory label:** Mark an older memory explicitly, including an approximate date or age only if known. Its appearance today does not mean the event happened today. [S4]

Optional additions: a retrieval tag, candidate status, or one unresolved question. Add them only if the user needs search or selection. No before-and-after analysis is required for routine capture.

| --- | --- | --- | --- | --- |
| [Short incident label] | [Owner's supported prior state] | [Specific event or recognition] | [Supported new state] | [Ready to develop / needs detail / anecdote / memory cue] |

**Selected candidate:** [Name and a short reason grounded in clarity, relatability, and available evidence.]

### Field guidance

- **Purpose and audience:** Use the user's setting to choose relevant material and length; do not impose a stage performance format. [S3][S6]
- **Before:** Record a belief, expectation, feeling, or self-understanding, not just the first external event.
- **Decisive moment:** Identify what made the change happen or become apparent. Do not force a literal five-second measurement.
- **After:** Describe the smallest defensible shift. A revised opinion is enough. [S3][S5]
- **Status:** If no shift is supported, retain the cue or anecdote. Ask for the missing inner experience only when development requires it.

## C. Selected story worksheet

**Working title:** [A retrieval label, not a promise of drama.]

**Format and length:** [Spoken story, essay, conversation, interview answer, or outline; requested limit.]

**Factual basis:** [User notes, transcript, or confirmed recollection; record consequential uncertainties.]

**Change in one sentence:** [I initially believed/felt/expected ___; when ___ happened, I came to ___.]

**Opening scene:** [Action in a recognizable place showing the prior state or a close counterpart.]

**Stakes:** [What I actually wanted, feared, risked, or misunderstood; what the audience wonders.]

**Essential context:** [Only information needed to understand the events; indicate where it enters after the opening.]

**Beat outline:**

1. [Opening action and prior state.]
2. [Relevant development, uncertainty, or real plan.]
3. [Pressure, discovery, or interaction that prepares the turn.]
4. [Decisive moment and new understanding.]
5. [Optional brief aftermath needed to make the change clear.]

**Draft:**

[Write the requested story here. Use supported facts, recognizable scenes, and the user's voice. Consider present tense for spoken scenes if suitable. Paraphrase unverified dialogue.]

**Unresolved questions:** [Specific missing facts that affect the draft; omit if none.]

**Review result:** [Ready / needs revision / needs owner detail, with the failed criterion if relevant.]

### Field guidance

The change determines the story's destination. Choose the opening backward from it, then keep only details that help the audience follow the turn. A plan can create anticipation when it actually existed. The outline is flexible: add or remove beats to fit the experience, rather than forcing every event into five slots. [S3][S5]

Keep factual questions and editorial notes outside the audience-facing draft. Leave placeholders in a working draft if answers are necessary; do not present that version as final. Where the story's internal turn is invisible, a short statement of thought can make it clear without attaching a sermon. These are agent adaptations described in [method.md](../references/method.md).
