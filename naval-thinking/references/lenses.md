# Lens reference index

The lenses are split by decision type to keep context focused:

- [Wealth and work](wealth.md): income versus assets, specific knowledge, building and selling, leverage, accountability, partners, focus.
- [Judgment](judgment.md): reality, identity, incentives, commitments, inversion, uncertainty, downside, learning.
- [Freedom](freedom.md): ambition, comparison, change/accept/leave, autonomy, small personal experiments.
- [Values and growth](values-and-growth.md): agency, fit, commitments, values, meaning, and personal inquiry.

For consequential decisions, [decision methods](decision-methods.md) add economics, evidence tests, and commitment criteria. For conflicting principles, [principle interactions](principle-interactions.md) explain which facts should resolve the tension.

Read only the relevant references. Source concepts are distinguished from this skill's application questions and limits within each file.
