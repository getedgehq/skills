# Creator squad operating plan template

Fill every applicable field. Write `Unknown` with an owner and next action where evidence is missing. Use `Not applicable` with a reason where a field does not apply. Bracketed fields are intended fill-in prompts. Label hypothetical numbers and implementation choices. This template supports a planning deliverable; it does not authorize external execution.
