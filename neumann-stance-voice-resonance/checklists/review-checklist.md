# Pass/fail review

This checklist operationalizes the reconstructed public method. It is package guidance, not an official Builderz audit. Use it on the requested scope; mark irrelevant items N/A with a reason. An unresolved factual, voice, or disclosure failure blocks a release-ready draft. Missing analytics may be recorded as a limitation instead of blocking useful writing.

## Review gates

- [ ] PASS / FAIL: The brief identifies a reader decision and useful business purpose.
- [ ] PASS / FAIL: The Stance is narrow enough to be recognizable and supported by the subject's experience.
- [ ] PASS / FAIL: Topic choices reinforce the position rather than merely filling a calendar.
- [ ] PASS / FAIL / N/A: Profile recommendations and posts carry the same position.
- [ ] PASS / FAIL: Each material factual claim is traceable to the subject's input or an identified verified source.
- [ ] PASS / FAIL: No experience, quote, number, credential, outcome, or belief has been fabricated.
- [ ] PASS / FAIL: A concrete situation, decision, or number supports the draft's judgment.
- [ ] PASS / FAIL: Important conditions and uncertainty survive the headline and editing.
- [ ] PASS / FAIL: The voice reflects observed samples; provisional assumptions are labelled.
- [ ] PASS / FAIL: The reader gains a useful perspective even if they never become a customer.
- [ ] PASS / FAIL: Sensitive details are cleared, genuinely anonymized, or removed.
- [ ] PASS / FAIL: The person can defend the claims and recognizes the draft as their thinking.
- [ ] PASS / FAIL: Subject approval is recorded, or the draft is clearly pending and held from publication.
- [ ] PASS / FAIL / N/A: Distribution specifies relevant contexts, useful contributions, owners, and realistic timing.
- [ ] PASS / FAIL / N/A: External publishing and messaging stay within explicit task authorization.
- [ ] PASS / FAIL / N/A: Measurement distinguishes delivery, interest, trust, and business outcomes.
- [ ] PASS / FAIL / N/A: Unavailable metrics are labelled; agency case results are not treated as guarantees.
- [ ] PASS / FAIL: Method attribution and agent adaptations are separated; no inaccessible material is cited as read.

## Common failure modes and fixes

| Failure | Diagnostic sign | Fix |
| --- | --- | --- |
| Broad positioning | The same sentence fits many unrelated experts | Specify the audience's decision and the subject's demonstrated answer |
| Generic agency voice | Smooth text without recognizable judgment or language | Return to speech samples and actual decision reasoning |
| Content without substance | A theme and opinion but no concrete support | Ask what happened, what was decided, and why |
| Fabricated proof | Attractive claim has no evidence ID | Remove it or request verification before proceeding |
| Forced provocation | Hook accuses more broadly than the evidence allows | Limit the claim and use niche-specific decision value |
| Confidential anecdote | An unnamed client remains identifiable | Remove identifying combinations or use different approved material |
| Calendar-first production | Draft exists only to meet a quota | Revisit the pillar or hold the slot until useful material exists |
| Passive distribution | Plan stops at publication | Add relevant responses, discussions, and an appropriate conversation path |
| Irrelevant reach | High reactions from people outside the intended market | Inspect audience fit and clarify the position |
| Overstated attribution | An inquiry or sale is credited solely to one post | Record what the prospect reported and other known contributing factors |
| Premature optimization | Daily fluctuations drive new positioning | Review over an appropriate period and change a supported hypothesis |
| Subject absent | Agent invents what the person would believe | Return a discovery brief with targeted questions |
