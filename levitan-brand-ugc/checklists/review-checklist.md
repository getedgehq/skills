# Brand UGC review checklist

Apply to the completed brief and scripts. Mark each item PASS, FAIL, or N/A with a reason. A FAIL on truthfulness, feasibility, or an objective mismatch prevents a ready-for-production verdict. Missing client inputs may support a provisional brief, provided dependencies are named. This is a package review tool, not a checklist published by Levitan.

## Pass/fail review

| Check | Pass condition | Result and evidence |
| --- | --- | --- |
| Assignment | Brand, audience, placement, offer, and requested action are explicit | [ ] |
| Diagnosis | Interchangeability or another actual problem is identified, with facts separated from hypotheses | [ ] |
| Motivation | A concrete audience friction connects to a relevant product capability | [ ] |
| Proof | Each material claim has a supplied source or is marked unverified and excluded from final script | [ ] |
| Brand premise | The recurring idea belongs to this brand and can sustain more than one episode | [ ] |
| Recognition | Stable cues connect executions without depending entirely on a closing logo | [ ] |
| Variation | Stable and variable elements are separated so the series can learn and refresh | [ ] |
| Format fit | The selected format helps explain or demonstrate the benefit within available resources | [ ] |
| Creator fit | The presenter has a believable role, product understanding, and natural-delivery freedom | [ ] |
| Truthful staging | Staged conversations and presenter relationships do not imply false independent endorsement | [ ] |
| Executability | Scripts identify spoken lines, visuals, evidence, and a relevant CTA | [ ] |
| Production | Required cast, setting, assets, permissions, and missing dependencies are specified | [ ] |
| Control | Working existing creative is retained as evidence or a comparable control where applicable | [ ] |
| Test isolation | Changes and confounders are disclosed; offer or destination repairs are not credited solely to format | [ ] |
| Outcome | The primary metric matches the assignment, including lead qualification where needed | [ ] |
| Definitions | Attention, clicks, conversion windows, and qualification are defined before comparison | [ ] |
| Boundaries | Spend limit, time window, decision rule, and insufficient-evidence outcome are recorded | [ ] |
| Interpretation | Public outcomes are contextual reports, never guaranteed results or universal targets | [ ] |
| Iteration | The next revision follows observed problems while retaining useful recognition elements | [ ] |
| Attribution | Core Brand UGC, later supporting guidance, and package adaptations remain distinguishable | [ ] |
| Credit | Levitan and Wobst receive joint credit for the original introduction | [ ] |
| Authorization | Delivering a brief is separated from commissioning, publishing, and advertising spend | [ ] |

## Common failure modes and fixes

| Failure | Why it fails | Fix |
| --- | --- | --- |
| Generic praise with a logo | The advertiser is labeled but the content remains interchangeable | Add a product-specific recurring premise and visible capability |
| Every execution has a different identity | Isolated hooks cannot build consistent recognition | Retain a small set of cues and vary the audience question |
| Podcast props without a useful conversation | A familiar set substitutes for product meaning | Give the host a concrete objection and the guide observable evidence |
| Fake expert or customer authority | Staging creates an unsupported credibility claim | State real roles and replace fabricated testimonials with demonstrations |
| Trend copied without audience relevance | Platform fluency does not answer the buying problem | Explain the trend's function or remove it |
| Over-scripted creator | The performance loses conversational credibility | Fix the facts and premise while permitting natural wording |
| Expensive format the team cannot repeat | Recognition depends on unsustainable production | Reduce cast, set, and shot complexity while retaining the series logic |
| Claimed recall lift from consistent colors | A design check is mistaken for an audience measurement | Describe intended recognition and propose measurement if needed |
| Good hook rate declared a business win | Attention may attract irrelevant viewers | Check qualified leads, purchases, and relevant costs |
| Cheap leads declared success | Raw forms can hide poor fit | Define qualified outcomes and inspect downstream response |
| Public CPL improvement used as forecast | Case context and causality do not transfer automatically | Use the client's baseline and explicit uncertainty |
| New format plus new offer credited to format | Multiple changed variables prevent isolation | Establish a comparable control or disclose the bundled test |
| Premature winner from small sample | Random variation can dominate | Report inconclusive evidence and respect the spend cap |
| Entire identity replaced at first decline | The team discards recognition without diagnosing the issue | Investigate opening, message, frequency, offer, and tracking first |
| Later profit guidance attributed to episode 283 | The chronology and source support are blurred | Cite the later sources and label contextual guidance |
| Detailed manual presented as a transcript | Available show notes do not substantiate every production rule | Label the practical workflow as an operational adaptation |

## Final verdict

- Verdict: [Ready for production brief / Provisional / Revisions required]
- Failed checks: [Items and concrete repairs]
- Remaining dependencies: [Facts, permissions, budget, measurement setup]
- Next authorized action: [Action within the user's scope]

A passing brief is ready for review or production planning. It does not establish that the format will outperform the control. Campaign results must supply that evidence.
