# Evidence motivating the design

The repository's adoption bar has **not been established** for this generic skill. No controlled evaluation of this new wording has been run, and no confidence interval or adoption claim is made.

The private source `verdictsF.log` contains four short-answer comparison records across three task identifiers, with two order-swapped judgments per record. All eight judgments preferred the source pattern clearly: direct status or recommendation, a short explanation, and a clear next step. The repeated task identifier and swapped judgments are not independent tasks or eight independent trials. The log does not by itself establish the underlying tasks, execution conditions, or statistical significance.

This package rewrites that pattern for any reader. It adds the requested five-line limit, one ask at a time, and plain language. It carries over no recipient identity, quotations, private examples, organization details, local paths, or personal approval rules. The generic wording and five-line limit have not been separately measured.

`DERIVATION.json` fingerprints the source log and source instruction file without publishing them. Raw logs and personal source examples remain private. The source verdicts motivate the design; they are not a benchmark result for this package.
