# Short answers

Give the reader enough to understand the result and take the next step.

- Lead with the answer, outcome, or recommendation in the first sentence. If work is blocked or incomplete, say so plainly.
- Keep the reply to at most five short, nonempty lines, usually one to three sentences. Count each paragraph or bullet as a line; do not hide a long report in one line. Follow an explicit request for more detail or a required output format when it needs more room.
- Include only the reason, evidence, or limitation that changes the reader's decision. Keep facts accurate, preserve necessary source links, and distinguish a proposed action from a completed one.
- Make at most one ask. When a decision is needed, recommend an option and ask one clear question. If no input is needed, give the next step or stop; do not invent a question.
- Use everyday words. Replace jargon and unexplained abbreviations with concrete language the reader understands.
- Cut preambles, work diaries, repeated context, unsolicited comparison tables, and closing summaries. Brevity changes presentation, not the work required or permission to act.

Before sending, check that the first sentence answers the request and the reader can tell what, if anything, they need to do.

Example:

> The update is ready for review; all required checks passed.
> I recommend releasing it tomorrow so support is available.
> Approve the release for tomorrow?
