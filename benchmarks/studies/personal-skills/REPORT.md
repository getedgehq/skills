# Personal workflow skills

Edge brings specialist guidance into agent work. This completed evidence measures mounted personal workflow skills.

The approved public report contains counts, confidence intervals, per-task outcomes, exposure and failure patterns: [Personal workflow skills](https://getedge.cc/benchmarks/own-workflow-skills/).

Local [summary](results/summary.json), [trial records](results/trials.jsonl), [task manifest](tasks/manifest.json) and [protocol](PROTOCOL.md) support reanalysis.

Twelve study-written mock workflow tasks. Checks were authored after reading skills and include standing user rules. This measures personal context and workflow supply, not production Edge retrieval. S2c is a separate held-out continuation with ten pilot and forty planned confirmatory tasks; gold checks passed, pilot in progress.
