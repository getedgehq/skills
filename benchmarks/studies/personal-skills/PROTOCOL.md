# Personal workflow skills

Question: Do mounted personal workflow skills improve task completion?

Protocol freeze: 2026-09-30. This date records the original design or amendment, not this export.

Method: native mounted skills. Planned tasks: 12. Arms: A, S. k: 2.

Twelve study-written mock workflow tasks. Checks were authored after reading skills and include standing user rules. This measures personal context and workflow supply, not production Edge retrieval. S2c is a separate held-out continuation with ten pilot and forty planned confirmatory tasks; gold checks passed, pilot in progress.

Primary metric: all task checks pass (reward = 1); partial credit secondary.


Supplied skill content, actual read/load exposure and outcome are separate measurements. Task-cluster paired effects cannot be compared as a global model ranking across different tasks and interventions.
