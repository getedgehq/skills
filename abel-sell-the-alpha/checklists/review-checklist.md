# Finished-output review

Mark each applicable item PASS or FAIL and cite a location in the brief. Use N/A only with a reason. An unknown buyer fact can pass if labeled honestly and paired with a useful validation action; invented certainty cannot. A brief can be ready for discovery without being ready to forecast a sale.

## Pass/fail checklist

- [ ] **Assignment:** PASS if product, account, role, stage, and main uncertainty are clear; FAIL if the brief is generic.
- [ ] **Motion:** PASS if pricing and selling effort match actual buying behavior; FAIL if small business success is assumed to prove enterprise readiness. [S2]
- [ ] **Entry point:** PASS if one customer profile, contained need, and accountable role anchor discovery; FAIL if the offer spans unrelated use cases. [S3]
- [ ] **Alpha:** PASS if the buyer's future capability and enabling mechanism are explicit; FAIL if features or unsupported superiority are the entire pitch. [S2] [S4]
- [ ] **Evidence:** PASS if buyer facts, hypotheses, assumptions, and unknowns are distinguishable; FAIL if unverified capabilities or commitments appear established. [S6]
- [ ] **Outreach:** PASS if three or four sentences earn interest through role relevance and a useful insight; FAIL if the message explains everything or fabricates personalization. [S6]
- [ ] **Discovery:** PASS if prior attempts, measurement, and ownership are investigated; FAIL if compliments are accepted as priority or broad wish lists replace the hypothesis. [S3]
- [ ] **Demo:** PASS if any demo addresses confirmed concerns with selected capabilities; FAIL if the first call is consumed by an indiscriminate tour. [S3] [S6]
- [ ] **Momentum:** PASS if next action and actual buyer commitment are separated; FAIL if vague email promises are counted as progress. [S6]
- [ ] **Engagement:** PASS if learning, evaluation, service entry, and deployment are distinguished with boundaries; FAIL if unfinished development is sold as a completed-product test. [S5]
- [ ] **Commercial frame:** PASS if price, scope, access, assumptions, and future expectations align; FAIL if a low introductory amount silently anchors unlimited annual enterprise access. [S2]
- [ ] **Buying path:** PASS if sponsor, procurement, IT, Finance, Legal, and payment approval are addressed or explicitly unknown; FAIL if the buyer is expected to solve procurement alone. [S8]
- [ ] **Value case:** PASS if hard savings have evidence and other value is separate; FAIL if hours saved are automatically presented as budget reduction. [S8]
- [ ] **Legal boundary:** PASS if contract interpretation is assigned to qualified counsel; FAIL if the brief substitutes agent judgment for legal advice. [S8]
- [ ] **Handoff:** PASS if any scaling recommendation rests on non-founder selling evidence; FAIL if logos or a revenue milestone alone justify a sales executive. [S7]
- [ ] **Deliverable:** PASS if the brief ends with a decision, concrete action, owner, and date or timing uncertainty; FAIL if it ends with vague encouragement.

## Common failure modes and fixes

| Failure | Repair |
| --- | --- |
| Grand vision with no credible mechanism | Narrow the alpha and define what discovery must validate. [S2] |
| Discovery becomes whatever the buyer feels like discussing | Return to the defined customer and unmet-need hypothesis; probe actual events. [S3] |
| A famous logo substitutes for readiness | Establish sponsorship, a relevant experiment, and implementation capacity. [S2] |
| Cheap annual land followed by an unexplained price jump | Clarify bounded introductory scope and discuss the future commercial destination before agreement. [S2] |
| A partner's custom request changes the target market | Test whether it generalizes to the chosen profile; decline or make a separate strategic decision. [S5] |
| Partner enthusiasm is declared product-market fit | Look for conversion into sustained paying use and transferable selling evidence. [S5] [S7] |
| A service entry has no end | Specify time, scope, learning, and the product transition; reassess if the buyer wants indefinite custom delivery. [S2] |
| Procurement stalls while the sponsor disappears | Requalify support and jointly map approvals before offering more concessions. [S8] |
| RFP work consumes the founder without buyer influence | Clarify whether the account is considering the startup seriously before substantial effort. [S8] |
| Hiring is used to escape market learning | Document and transfer judgment under founder management before scaling. [S7] |

A FAIL requires revision or an explicit unresolved issue and next validation action. Do not hide missing commercial evidence with stronger prose.
