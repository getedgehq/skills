# Rocketmap reference

Explore [Rocketmap](https://rocketlist.ai/map), the live production map of startup hiring. It is the visual reference for Data Globe’s globe, filters, company selection and street fly-to.

The starter contains generic UI and normalization tools. Use your own dataset and labels; no Rocketlist product data, copy or brand assets ship in the starter. Rocketmap is reference proof, while the airport example on the Edge page is output from a fresh agent run using this skill.

Recorded clips and their counts describe the captured snapshot. Open the production map and linked source roles for current hiring.
