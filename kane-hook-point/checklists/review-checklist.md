# Hook Point review checklist

This checklist operationalizes the public principles explained in [method.md](../references/method.md). It is a package-created review tool, not an official Kane scoring system.

Mark each applicable item PASS or FAIL and record the concrete evidence. Use N/A only for a format-specific item that does not apply. A failed material claim, promise mismatch, or missing core deliverable blocks a ready-to-use handoff. Missing audience validation can remain a disclosed uncertainty in a draft; it cannot support a claimed winning result.

## Assignment and evidence

- [ ] PASS / FAIL: The audience, encounter, value, channel, and primary outcome are explicit.
- [ ] PASS / FAIL: Facts, assumptions, creative hypotheses, and observed results are distinguishable.
- [ ] PASS / FAIL: Material claims have available support or have been removed or qualified.
- [ ] PASS / FAIL: Relevant strong and weak references inform the proposal, or absent research is disclosed.
- [ ] PASS / FAIL: Source references support claims about Kane's public method; package adaptations are identified.

## Opening

- [ ] PASS / FAIL: The reason to care appears in the first exposed words or opening video experience.
- [ ] PASS / FAIL: The opening is understandable in its audience's context without delayed explanatory setup.
- [ ] PASS / FAIL: The hook is meaningfully distinctive from routine category messages.
- [ ] PASS / FAIL: Video timing has been read or inspected at realistic speed; written truncation has been considered where relevant.
- [ ] PASS / FAIL / N/A: The visual, spoken line, and on-screen text reinforce one understandable premise.
- [ ] PASS / FAIL: Alternatives test distinct reasons for attention rather than cosmetic differences alone.

## Story, trust, and conversion

- [ ] PASS / FAIL: The story directly develops the hook's promise.
- [ ] PASS / FAIL: The promised payoff is present and identifiable.
- [ ] PASS / FAIL: Attention renewals add actual discovery, tension, or useful information.
- [ ] PASS / FAIL: Product introduction and proof occur without crowding out the opening's purpose.
- [ ] PASS / FAIL: The message remains credible, including any important qualifications.
- [ ] PASS / FAIL: Length serves sustained useful attention and the brief rather than an invented universal rule.
- [ ] PASS / FAIL: The CTA offers a clear, proportionate action related to the value delivered.
- [ ] PASS / FAIL: The destination continues the same promise and is identified.

## Testing and handoff

- [ ] PASS / FAIL: The candidate selection is explained as editorial judgment unless supported by actual audience evidence.
- [ ] PASS / FAIL: The test names a hypothesis and the element being changed.
- [ ] PASS / FAIL: Comparison conditions and unavoidable confounds are recorded.
- [ ] PASS / FAIL: Primary outcome, opening attention, and retention measures have usable definitions where available.
- [ ] PASS / FAIL: The plan includes bounded exposure and an inconclusive outcome when evidence is insufficient.
- [ ] PASS / FAIL: No historical example budget or agency result is presented as a current default or guaranteed outcome.
- [ ] PASS / FAIL: The handoff contains usable copy or a script, finalists, promise map, and test plan.
- [ ] PASS / FAIL: Proposed publishing, outreach, or paid testing stays within the user's authorization.

## Common failure modes and fixes

| Failure | What to inspect | Fix |
| --- | --- | --- |
| Generic expert introduction | First exposed line or pre-roll | Replace setup with a recognizable situation or visible demonstration; introduce expertise as relevant proof |
| Surprise without relevance | Relationship between hook and audience value | Use an unexpected context tied to the actual message |
| Inflated numerical promise | Source and applicability of the number | Show a substantiated demonstration or remove the claim |
| Attention rises, early retention falls | Opening-to-story transition | Remove delay, resolve promise mismatch, and inspect premature selling |
| Teasing repeated without progress | Each attention renewal | Add new information, a real complication, or the payoff |
| Good watch time, few qualified actions | Audience, offer, CTA, destination | Repair the next step or qualification before intensifying the hook |
| Copied popular script | Words, signature expression, and assumptions | Transfer the storytelling structure and supply original voice, facts, and demonstration |
| Winner selected from views alone | Business objective and conversion data | Evaluate the intended action alongside attention and retention |
| Random variant volume | Changed elements and hypotheses | Test distinct, informed mechanisms under comparable conditions |
| Tiny or uneven exposure | Denominators and distribution context | State uncertainty and plan another bounded comparison |
| Three-second rule applied to total length | Whether useful attention continues | Keep the opening immediate and let the story length serve the content |
| Agency metrics treated as proof of causation | Source ownership and study design | Attribute self-reports and remove universal performance promises |
| Proprietary framework invented | Which mechanics are publicly documented | Use only public principles and clearly labeled package tools |
